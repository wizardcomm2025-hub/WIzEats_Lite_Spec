Feature developer guide · PRN

Printer settings & printing

One Wi-Fi receipt printer per device: find it, save it, test it, and the route every bill and KOT print takes to reach it.

v1 scope

Three use cases: find and save a printer, check and test print, print a bill or KOT. Device only, so there are tester cases only. See the README. The spec records today's behaviour. PRN-D1 to D3 keep the current rules as accepted risks.

How it works end-to-end

The Printer screen stores { ip, port } in AsyncStorage (WIFI_PRINTER). Every print button builds an 80 mm PDF and calls printPdf(). With a saved printer on Android, WifiPrinter.printPdf renders it to 576-dot images and prints them silently. On failure, the app scans the network once and either switches printer silently, or alerts and opens Android's print screen (PdfPrint).

What matters where you sit

POS app

  • A single address found after a failure is printed to and saved with no prompt (PRN-D1).
  • The port isn't validated: Number(port) || 9100, with no upper bound (PRN-D2).
  • Bill print errors use the title Share Failed; the Invalid IP alert can't be reached (PRN-D2).
  • The setting is per device and survives sign-out (PRN-D3).

Android native

  • WifiPrinterModule: reachability is a plain TCP connect (3 × 5 s), so any open port counts. There is one job queue, plus a separate scan pool (64 threads, 0.5 s).
  • Status -2 / -4 → out of paper / cover open.
  • PdfPrintModule resolves when the dialog opens, never with the outcome.

POS API / Data — MySQL / Super-admin panel

None.

Integrations

SPRT printer SDK (com.printer.sdk), react-native-html-to-pdf, react-native-share (iOS fallback).

Accepted risks (do not "fix" without a new decision)

  • PRN-D1: any listening device counts as a printer; silent switch and save after a failed print.
  • PRN-D2: no port check, alert and print screen together, outcome unknown, Share Failed title, no remove confirmation, iOS share sheet only.
  • PRN-D3: device-wide setting that survives sign-out and restaurant changes; chefs have no screen.
