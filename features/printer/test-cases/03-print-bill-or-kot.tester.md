# 03 — Print a bill or KOT — tester cases

Use case: [03-print-bill-or-kot.md](../03-print-bill-or-kot.md). Screen text: [ui-ux.md](../ui-ux.md). Fixtures: [README.md](./README.md#fixtures) (CLEAN before each case).

"Send a KOT" = Home → Takeaway → add `Paneer Tikka` → send the KOT (ORD). The KOT card then shows `Print KOT` (phone). "Print screen" = Android's own print dialog.

| ID | Covers | Steps | Expected |
|---|---|---|---|
| PRN-03-T01 | AC1 | Save PRN-1. Send a KOT. Tap `Print KOT`. | The button spins; PRN-1 prints the KOT at full width and cuts it. No print screen, no alert. |
| PRN-03-T02 | AC1 (tablet) | On DEV-T: save PRN-1, send a KOT, tap `Print` on the KOT banner. | As T01. |
| PRN-03-T03 | AC2 | Nothing saved. Send a KOT; tap `Print KOT`. Then press Back on the print screen. | The print screen opens with a job named `KOT #<KOT number>`. After Back: no alert; nothing printed. |
| PRN-03-T04 | AC1, AC2 | ORDER-H in Order History → History tab, expand the card. (a) With PRN-1 saved, tap `Print Bill No. <n>`. (b) With nothing saved, tap it again. (c) Pay another order in the app and tap `Print Bill` on the success screen with PRN-1 saved. | (a) `Printing…`, then PRN-1 prints the bill and cuts it; no screen. (b) The print screen opens with the job `Bill No. <n>`. (c) As (a). |
| PRN-03-T05 | AC3 — *Fails until PRN-D2 is fixed* | Save PRN-1, then switch it off. Send a KOT; tap `Print KOT`. Tap `OK`. | After about 15 s: alert `Printer not reachable` / `Printer not reachable at <PRN-1 ip>:9100.` / `Opening the print screen instead.`; the print screen opens only after `OK`. The Printer screen still shows PRN-1. (Today: the alert and the print screen open at the same time.) |
| PRN-03-T06 | AC4 — *Fails until PRN-D1 is fixed* | Save PRN-1, switch it off, switch PRN-2 on. Send a KOT; tap `Print KOT`. Tap `Print on <PRN-2 ip>`. Open the Printer screen. | After about 15 s, nothing has printed yet: alert `Printer not reachable` / `Printer not reachable at <PRN-1 ip>:9100.` / `Another printer answered on this Wi-Fi.` with `Print on <PRN-2 ip>` and `Open print screen`. After the tap the KOT prints on PRN-2 and the alert `Printer saved` / `Bills and KOTs will now print to <PRN-2 ip>.` shows; the Printer screen reads `Printing to <PRN-2 ip>`. Repeat and tap `Open print screen` instead: the print screen opens and PRN-1 stays saved. (Today: the KOT prints on PRN-2 at once, with no message, and PRN-2 is saved.) |
| PRN-03-T07 | AC4 — *Fails until PRN-D1 is fixed* | Save PRN-1, switch it off; PRN-2 on; start DECOY. Send a KOT; tap `Print KOT`. | Alert `Printer not reachable` / … / `Another printer answered on this Wi-Fi.` with `Print on <PRN-2 ip>`, `Print on <DECOY ip>` (address order) and `Open print screen`. Nothing printed or saved until a choice. (Today: `Several printers were found. Choose one in Setup → Printer.` / `Opening the print screen instead.` and the print screen at once; PRN-1 stays saved.) |
| PRN-03-T08 | AC5 — *Fails until PRN-D1 is fixed*, *Fails until PRN-D2 is fixed* | Save PRN-1; take its paper out; switch PRN-2 on. Send a KOT; tap `Print KOT`; tap `OK`. | Alert `Printer not reachable` / `The printer is out of paper.` / `Opening the print screen instead.` with no `Print on …` button (no search); the print screen opens after `OK`. Nothing prints on PRN-2; the saved printer stays PRN-1. (Today: the KOT prints on PRN-2 and PRN-2 is saved, with no message. With PRN-2 off: the alert and the print screen at once.) |
| PRN-03-T09 | Alt: bad port (today only) | Save PRN-1 with port `70000` (possible only before PRN-D2 is fixed — PRN-01-T10). Send a KOT; tap `Print KOT`. | Almost at once: alert `Printer not reachable` / `Printer not reachable at <PRN-1 ip>:70000.` / `Opening the print screen instead.`, and the print screen opens. Once PRN-D2 is fixed this case is skipped. |
| PRN-03-T10 | Alt: long receipt | Save PRN-1. Send a KOT with 30 different items. Tap `Print KOT`. | The whole KOT prints at full width (not shrunk), with one cut at the end. |
| PRN-03-T11 | Alt: double tap | Save PRN-1. Send a KOT; tap `Print KOT` twice quickly. | One KOT prints (the second tap is ignored while the first runs). |
| PRN-03-T12 | Alt: iOS (if an iPhone build exists) | On an iPhone, send a KOT; tap `Print KOT`. | The share sheet opens with the KOT PDF. On the Printer screen, `Search printers` does nothing (no list, no message) and no built-in tab shows. |

| PRN-03-T16 | USB failure | On USB-T, save USB-2 (PRN-01-T14), then unplug USB-2 (leave the other printer in). | PRN-03-T17 | USB permission | On USB-T with the USB printer saved, clear the app's USB permission (reinstall the app or re-plug an external printer). Send a KOT; tap `Print KOT`; allow Android's dialog. Repeat and deny it. | Allowed: the KOT prints once the dialog is answered. Denied: alert `Printer not available` / `Allow this app to use the USB printer and try again.` and the print screen. |
