# 03 — Edit restaurant and configuration in the panel — developer cases

Use case: [03-edit-in-panel.md](../03-edit-in-panel.md). Contract: [api-contract.md → Panel routes](../api-contract.md#panel-routes-web). Fixtures and how to call the panel: [README.md](./README.md#panel-requests-use-case-03).

All POSTs: JSON with ADMIN-1's session cookies and a valid `X-CSRF-TOKEN` unless stated. REST-A reset to REST-A-BASE before each case. "Details body" = `{ restaurantId: <REST-A hex>, restaurantName, restaurantContact, restaurantOwnerName, restaurantGstId, restaurantFssaiId, restaurantAddress }` with REST-A-BASE values. "Config body" = `{ restaurantId: <REST-A hex>, enableRestaurant: 1, enableDelivery: 0, enableKOT: 1, enableRoomService: 0, taxPercent: "5", serviceChargePercent: "", invoicePrefix: "" }`. "422 `<msg>`" = the Laravel JSON `{ "message": "<msg>", "errors": {…} }` (send `Accept: application/json`). Cases tagged *Fails until … is fixed* assert the target.
