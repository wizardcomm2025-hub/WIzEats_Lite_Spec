Feature developer guide · ROOM

Floors & rooms

Floors and rooms for Room Service. It copies the zones and tables module. The GUID conversion was added on 2026-11-16, so floors and rooms can now be managed from the app.

v1 scope

Two use cases: manage floors and manage rooms. See the README. The spec records today's behaviour plus targets (re-synced 2026-11-24): ROOM-D1 is fixed in code and in the app; ROOM-D2 to ROOM-D6 are To fix.

How it works end-to-end

With Room Service on (RST), the owner's menu shows Floor Management and Room Management. FloorManagementScreen lists floors through getFloorDetails and saves through floorSave. RoomConfigScreen lists rooms per floor through getRoomsDetails and saves through roomSave. RoomService converts hex IDs with hex2bin (since 2026-11-16). The Room Service order screen (ORD) reads the same floors and rooms and sets a room's status through roomSave.

What matters where you sit

POS API

  • Floor update, room create / update and the room list's floorId filter convert hex (ROOM-D1 fixed).
  • Leftovers (ROOM-D4): floorId on room update is not converted (500); the roomId filter is ambiguous with orders.roomId (500); the floor list's floorId filter never matches; two running orders give two rows.
  • floorId on room create isn't checked against floors (orphans — ROOM-D3).
  • No role checks; the Room Service setting isn't checked; no rate limits. Target roles (ROOM-D2): reads owner + waiter; floorSave owner; roomSave owner, or waiter with only { roomId, status }.

Data — MySQL

  • floors and rooms, both keyed by binary(16).
  • The list returns active rooms only, so an inactive room can't be found again in the app (target includeInactive — ROOM-D5).

POS app

  • The room filter compares IDs as strings (ROOM-D1 fixed).
  • Failed adds and renames are silent (target ROOM-D6, like TBL-D5); a failed switch shows the server message.

Super-admin panel

No floor or room pages. The panel only switches Room Service (RST).

Integrations

None. Import (IMPEX) can also create floors and rooms.
