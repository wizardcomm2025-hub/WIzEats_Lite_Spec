Feature developer guide · ORD

Take an order & send KOTs

Channels, the table grid, creating an order with its first KOT, adding KOTs, and reading a running order back.

v1 scope

Four use cases: choose a channel and table, send the first KOT, add a KOT, and view a running order. See the README. The spec records today's behaviour plus targets (re-synced 2026-11-24): ORD-D2 is fixed in code and the app; ORD-D1, ORD-D3 and ORD-D4 are To fix.

How it works end-to-end

Home lists getOrderChannels. Dine In shows showDetails zones and tables. Occupy / leave call TBL's tableSave (rooms: ROOM's roomSave) with status 1 / 0; a first KOT sets 2, and a table with an orderId opens its cart. The cart's submitKot posts createOrder; the cart then keeps the hex orderId, and later sends go to kots/{orderId}. KotService numbers the order and the KOT, copies the tax %, and stores each line with the app's name and price. orders/{orderId} returns the live KOTs, or the bill snapshot.

What matters where you sit

POS API

  • Prices, names and item IDs are trusted (ORD-D1). The channel, table and room IDs aren't checked against the restaurant.
  • Table / room status updates convert the hex ID (ORD-D2 fixed 2026-11-16). The customer fields are gated on orderChannelId == 2 (ORD-D3).
  • "Last" order / KOT are found by created_at since 2026-11-16; with no lock, parallel requests can still share a number (ORD-D3).
  • No Idempotency-Key support. Raw exception text goes out in error / message (ORD-D4).

Data — MySQL

  • A KOT has no orderId; it links through order_items.
  • grandTotal / taxAmount stay 0 until BILL.
  • Adding a KOT locks the order row (FOR UPDATE).

POS app

  • Sends the table / room hex ID and requests /orders/<hex>; getOrders rebuilds its shape from the flat reply (ORD-D2 fixed).
  • getCustomerInfoRequirement checks channel IDs '0'–'2', so the customer block never shows (ORD-D3).
  • A KOT is never empty; held items stay in the cart; one submission at a time.

Super-admin panel

None.

Integrations

None on the server. KOT print / share is on the device (PRN).
