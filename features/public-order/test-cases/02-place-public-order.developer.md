`POST /api/public/order`, JSON, no token, no `orderId`, header `Idempotency-Key: <new UUID>` unless a case says otherwise.
- **"Created"** = 201 `{ status: true, message: "Order created successfully", data: { orderId (32 hex), orderNumber, kotId (32 hex), kotNumber (integer), subTotal } }`; one new `orders` row (`createdBy` `customer`, `orderStatus` 0, `taxPercent` 5.00), one `kots` row, one `order_items` row per line.

- **"Unchanged"** = every value matches ROW-SNAP.
