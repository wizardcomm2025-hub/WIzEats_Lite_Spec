`POST /api/public/order`, JSON, no token, header `Idempotency-Key: <new UUID>`. "Body+" = PUB-BODY with the items replaced by `[ { "menuItemId": "<ITEM-2 hex>", "quantity": 1 } ]`, plus `orderId`. "Added" = 201 `{ status: true, message: "KOT added successfully", data: { orderId, orderNumber, kotId, kotNumber, subTotal } }`, one new `kots` row and one new line. "Not found" = 404 `{ status: false, message: "Order not found", data: null }`. Today every 500 is `{ status: false, message: "Something went wrong", error: <text> }`.
