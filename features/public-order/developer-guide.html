Feature developer guide · PUB

Public QR ordering

Two open endpoints for customers who scan a QR code: read a restaurant's menu, and place or add to an order without signing in.

v1 scope

Three use cases: load the menu, place an order, add to an order. There is no customer UI, so all cases are developer cases. See the README. The spec records today's behaviour plus targets (re-synced 2026-11-24; no code change since 2026-11-12). PUB-D1 to PUB-D3 are To fix: the target is a working, checked public API — the only source of Delivery orders (DLV-D4).

How it works end-to-end

public/menu reads the restaurant, tax, active channels and items by the restaurantId in the body. public/order creates an order with its first KOT, or, when orderId is sent, adds a KOT to that order. Neither route has any middleware.

What matters where you sit

POS API

  • IDs are used as sent, with no hex2bin. A hex restaurantId matches nothing, so the menu comes back empty.
  • Create: the channel is fixed to 3; the insert names the missing orders.orderChannel column; the reply is 500 with the SQL text (PUB-D1, D3).
  • Create reads $validated['tableId'] and ['roomId'], so both keys must be sent.
  • Add: addKotToPublicOrder(int $orderId). A hex ID gives a TypeError with the file path; 0 matches some order of the restaurant sent.
  • Prices, names and item IDs come from the client; the menu includes inactive and deleted items (PUB-D2).

Data — MySQL

  • kots / order_items inserts give no primary key: strict-mode error 1364.
  • Everything runs in one transaction, so failures leave no rows.

POS app

Never calls these endpoints. Its QR codes are UPI payment codes.

Super-admin panel

None.

Integrations

The Google Sheet error log (GOOGLE_SHEET_LOG_URL) receives each failure, including the SQL text with customer details.

Accepted risks (do not "fix" without a new decision)

  • PUB-D3 (part): no captcha or bot check — the rate limits are the only guard.
  • Any approved restaurant's active menu is readable by anyone with its ID (by design).
