# 01 — Register a new restaurant — developer cases

Use case: [01-register-restaurant.md](../01-register-restaurant.md). Contract: [api-contract.md](../api-contract.md#post-apirestaurantssetup). Fixtures: [README.md](./README.md#fixtures).

All requests: `POST /api/restaurants/setup`, **no** `Authorization` header unless stated. "full" = the full body from the README plus `phone` = a fresh PH-NEW number. 422 bodies are `{ "status": false, "message": "<text>", "errors": {…} }`. "Nothing written" = no new row in `restaurants`, `users`, `restaurant_configs`, `zones`, `tables`, `order_channels`, `personal_access_tokens`, and no e-mail.
