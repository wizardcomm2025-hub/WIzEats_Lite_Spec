Feature developer guide · MENU

Menu — categories & items

Categories, menu items with prices and photos, the paged ordering menu, a base64 image endpoint, and two panel pages. Since 2026-11-18 reads and writes work from the app; the panel Items page, image checks and some server limits are still to fix.

v1 scope

Four use cases: manage categories, manage menu items, the menu in the panel, and image upload. See the README. The spec records today's behaviour plus targets (re-synced 2026-11-24): MENU-D1 and MENU-D2 are fixed; MENU-D3 to MENU-D6 are To fix.

How it works end-to-end

MenuCategoryScreen reads getItemsCategory (categories, each with all its items) and creates, edits and switches categories through categorySave. MenuItemManagementScreen pages one category's items through showCategoryMenuItems and saves through menuItemSave, which can carry a base64 image. The ordering screen loads the whole active menu through getMenuItems (100 per page). The panel's categories and items pages write with the query builder.

What matters where you sit

POS API

  • ItemService converts IDs with hex2bin (MENU-D2 fixed), except the getItemsCategory filter.
  • saveMenuItem (rewritten 2026-11-18) checks: menuItemId hex, price > 0, own non-deleted category, non-blank name, unique name per category. saveCategory checks unique category names (deleted ones count today).
  • Still to fix (MENU-D4): owner-only writes, price / length limits as 422, 404 for unknown IDs, 422 for malformed list filters, deleted items in items.
  • /api/image/upload catches its own failure and still answers 201; no content or size check (MENU-D5).

Data — MySQL

  • price is decimal(10,2). isVeg defaults to false through the API, but to 1 in the column.
  • Image files are never cleaned up (target: a replaced image's file is deleted — MENU-D5).

POS app

  • Add sends menuItemId: "" (MENU-D1 fixed); IDs are compared as strings (MENU-D2 fixed).
  • Category and item sheets close only on success and toast the server message on failure. A category switch is optimistic, then reverted on failure.
  • The Edit Category sheet starts with an empty description and clears it on save (MENU-D6).

Super-admin panel

The Categories page works, and its switch doesn't cascade. The Items page writes menuItemName (wrong column) and renders raw binary IDs (MENU-D3 — to fix, with the API's item rules and a cascading category switch).
