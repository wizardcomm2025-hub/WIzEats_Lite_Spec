Feature developer guide · MENU

Menu — categories & items

Categories, menu items with prices and photos, the paged ordering menu, a base64 image endpoint, and two panel pages. Reading works; most writes fail today.

v1 scope

Four use cases: manage categories, manage menu items, the menu in the panel, and image upload. See the README. The spec records today's behaviour; MENU-D1 to D4 keep the current rules as accepted risks.

How it works end-to-end

MenuCategoryScreen reads getItemsCategory (categories, each with all its items) and creates categories through categorySave. MenuItemManagementScreen pages one category's items through showCategoryMenuItems and saves through menuItemSave, which can carry a base64 image. The ordering screen loads the whole active menu through getMenuItems (100 per page). The panel's categories and items pages write with the query builder.

What matters where you sit

POS API

  • ItemService converts IDs with hex2bin only for categoryId on item create. Every other ID lookup compares hex with binary (MENU-D2).
  • filled('menuItemId') is true for 0, so the app's create runs the update rules (MENU-D1).
  • No role checks, no price bounds, no category ownership check, no rate limits.
  • /api/image/upload catches its own failure and still answers 201.

Data — MySQL

  • price is decimal(10,2). isVeg defaults to false through the API, but to 1 in the column.
  • Image files are never cleaned up.

POS app

  • The menuItemId: editingItem?.menuItemId || 0 payload (MENU-D1).
  • The Item Management filter Number(item.categoryId) === Number(selectedCategoryId) (NaN === NaN).
  • Category add / edit errors are never shown. A switch is optimistic, then reverted.

Super-admin panel

The Categories page works, and its switch doesn't cascade. The Items page writes menuItemName (wrong column) and renders raw binary IDs (MENU-D3).

Accepted risks (do not "fix" without a new decision)

  • MENU-D1: Add Menu Item fails in the app.
  • MENU-D2: category and item edits and switches fail; Item Management is always empty.
  • MENU-D3: the panel Items page add / edit / switch don't work.
  • MENU-D4: no role, price, category or image checks; the upload answers 201 on failure.
