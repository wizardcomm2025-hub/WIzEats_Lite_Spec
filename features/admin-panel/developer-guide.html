Feature developer guide · ADM

Super-admin panel (shell & reports)

Sign-in, the restaurant directory, each restaurant's Overview, Order History and Item History, and the language switch of the Blade panel.

v1 scope

Five use cases. The panel's settings, users, zones and tables, menu and approval pages belong to RST, STAFF, TBL, MENU and ONB. See the README. The spec records today's behaviour plus targets (re-synced 2026-11-24; no panel code changed). ADM-D2 is To fix (aligned with RPT); ADM-D1 and ADM-D3 stay accepted.

How it works end-to-end

A JSON sign-in (POST /admin/login) creates an admin-guard session. /admin lists onboarded restaurants. /admin/analytics|orders|items/{hexId} run DB::table queries on the binary ID and render Blade with Chart.js. /set-locale/{locale} sets the session locale for SetLocale.

What matters where you sit

Super-admin panel

  • No roles; status is checked only at sign-in; the remember cookie lasts about 400 days; /set-locale redirects to any Referer (ADM-D1).
  • Today revenue = paid (orderStatus 2) only; orders, items and channels = all; UTC days; "Last n days" = n + 1 days; an unknown filter = all time (ADM-D2 — to fix).
  • itemhistory passes sort_order straight to orderBy: an invalid value gives a 500 (ADM-D2).
  • /dashboard is static demo HTML; several buttons are dead; an unknown ID gives zeros, not a 404 (ADM-D3).

Data — MySQL

  • super_admins is maintained by SQL only; sessions live in the sessions table.
  • All panel reads are on orders, order_items and order_channels by binary restaurantId.

POS app / POS API

None. Panel sessions and API tokens don't cross over.

Integrations

CDN assets (Tailwind, Bootstrap, Font Awesome, Chart.js, Google Fonts).

Accepted risks (do not "fix" without a new decision)

  • ADM-D1: SQL-only accounts, sessions outlive deactivation, about 400-day remember cookie, no roles, IP-only throttle, Referer redirect.
  • ADM-D2 (part): Item History merges items with the same name.
  • ADM-D3: fake /dashboard, dead buttons, page-only search, numbering per page, zeros for unknown IDs, untranslated tables.
