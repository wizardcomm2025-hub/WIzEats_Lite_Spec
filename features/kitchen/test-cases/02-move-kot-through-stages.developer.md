# 02 — Move a KOT through its stages — developer cases

Use case: [02-move-kot-through-stages.md](../02-move-kot-through-stages.md). Contract: [api-contract.md](../api-contract.md#post-apichefupdate-statuskotid). Fixtures: [README.md](./README.md#fixtures).

`POST /api/chef/update-status/<id>`, JSON, CHF-A's token unless stated; `<id>` is the KOT's hex unless stated. "Updated(L)" = 200 `{ status: true, message: "KOT status updated successfully", data: { kotStatus: "L" } }`. "Fail-500" (today) = 500 `{ status: false, message: "Something went wrong", data: null }`. "Times" lists `preparing_at / rejected_at / completed_at`. Cases tagged *Fails until … is fixed* assert the target; today's result is in brackets.
